# Meu primeiro projeto no lovable

Crie um sistema de cadastro de pessoas em português do Brasil. Uma página com um formulário com os campos: nome completo, e-mail, telefone e cidade. Valide se o nome e o e-mail foram preenchidos e se o e-mail é válido, mostrando mensagem de erro. Ao enviar, mostre uma mensagem de sucesso e adicione a pessoa em uma lista de cadastrados abaixo do formulário, com opção de excluir. Visual limpo e moderno, que funcione bem no celular.

This project was built with [Lovable](https://lovable.dev).
